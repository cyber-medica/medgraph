# Google Search Console + Яндекс Вебмастер baseline

Use this checklist after the approved release. Record observed data; do not infer SEO changes from an empty or delayed report.

## Shared checks

- [ ] `https://cyber-medica.ru/sitemap.xml` accepted and last read time recorded.
- [ ] Submitted URL count and indexed URL count recorded.
- [ ] Excluded URL groups exported with reasons and examples.
- [ ] Crawl errors and response-code groups exported.
- [ ] Core Web Vitals status recorded separately for mobile and desktop.
- [ ] Manual actions / security issues checked and recorded.
- [ ] Top queries, pages, countries and devices exported for the selected period.
- [ ] Impressions, clicks, CTR and average position recorded with date range.
- [ ] Query-parameter examples checked for clean canonical and intended robots policy.

## Google Search Console

- [ ] Page indexing: indexed / not indexed and dominant exclusion reasons.
- [ ] Sitemaps: success state, discovered pages and fetch date.
- [ ] Core Web Vitals: good / needs improvement / poor URLs.
- [ ] Enhancements: Breadcrumb and detected structured-data reports.
- [ ] URL Inspection samples: homepage, catalog, manufacturer, `/about`, `/contacts`, one category and one Product.

## Яндекс Вебмастер

- [ ] Индексирование → Страницы в поиске / исключённые страницы.
- [ ] Диагностика → фатальные, критичные и возможные проблемы.
- [ ] Индексирование → Файлы Sitemap.
- [ ] Поисковые запросы → показы, клики, CTR и позиция.
- [ ] Качество сайта / скорость и мобильность recorded without speculative fixes.

## Evidence format

For every exported metric record service, property, date/time (MSK), date range, filter and source screenshot/export. Do not commit account credentials, user email, RFQ PII or browser session data.
